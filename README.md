# Mini Project 1: Product Information System

Sistem Manajemen Data Informasi Produk Berbasis PHP.

## Komponen Arsitektur:
1. *Data Layer (products.php)*: Menampung multidimensional array data produk.
2. *Processing Layer (functions.php)*: Fungsi kalkulasi nilai stok & penanda stok kritis.
3. *Presentation Layer (index.php)*: Merender data ke dalam tabel HTML.
